📖 Sobre o projeto

O Drip Store é um projeto de interface de e-commerce desenvolvido em Front-end, criado com o objetivo de praticar a construção de layouts modernos, organização de componentes e desenvolvimento de interfaces responsivas.

Este projeto foi desenvolvido como prática de desenvolvimento web, focando na implementação de layouts e na experiência visual do usuário.



🚀 Tecnologias utilizadas:

As seguintes tecnologias foram utilizadas no desenvolvimento do projeto:

HTML5 → Estrutura da aplicação

CSS3/TailwindCSS → Estilização e layout responsivo

JavaScript → Interatividade da interface

Git → Controle de versão

GitHub → Hospedagem do repositório

React + Vite → Framework



Para obter uma cópia do projeto na sua máquina, execute os seguintes passos:

1️⃣ Clonar o repositório
git clone https://github.com/ronei-dev/projeto-front-end-drip-store.git
2️⃣ Acessar a pasta do projeto
cd projeto-front-end-drip-store


▶️ Como executar o projeto

Este é um projeto front-end estático, portanto pode ser executado diretamente no navegador.


Se estiver utilizando Visual Studio Code:


Abra o projeto no VS Code.

Abra seu terminal, de preferência o git bash.

Instale as dependências necessárias com npm install.

Insira o comando npm run dev.

O projeto será executado em um servidor local.
